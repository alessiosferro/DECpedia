# DECpedia 1.4.1

Questa versione di manutenzione sposta il nome DECpedia al centro della barra della finestra: il titolo non invade più il separatore quando la barra laterale è chiusa. Il gioco sulle curve ora richiede davvero la riflessione per raggiungere l’obiettivo del livello avanzato. Nei tabelloni risolti le formule conservano un contrasto leggibile.

Gli undici minigiochi sono stati completati manualmente in italiano e in inglese, con i temi chiaro, scuro e automatico: 198 percorsi, 33 per ciascuna combinazione. Verifica automatizzata: 26 test superati e 12.927 formule LaTeX controllate senza errori.

# DECpedia 1.4.1

This maintenance release centers the DECpedia name in the window toolbar, so it no longer overlaps the divider when the sidebar is closed. The advanced curve game now requires reflection to reach its goal. Formulas remain legible on completed boards.

All eleven logic games were completed manually in Italian and English with light, dark, and automatic appearance: 198 runs, 33 for each language-and-theme combination. Automated checks: 26 tests passed and 12,927 LaTeX expressions validated without errors.
